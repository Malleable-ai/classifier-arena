# Assets

Every visual, audio and data asset in the repo, with its source, author, license and the files it
covers. The code is MIT. Art is original and drawn in code; files under `data/` keep their own
licenses ([data/NOTICE.md](../data/NOTICE.md)).

The tree has no image, font or sound files: `git ls-files` lists no `png`, `jpg`, `svg`, `gif`,
`webp`, `ico`, `woff`/`woff2`, `ttf`, `otf`, `mp3`, `wav` or `ogg`. The one video file is the square
cut of the published results, generated by the repo itself (see "Video" below). The page has no
favicon (`<link rel="icon" href="data:,">` in `index.html`). The models are named in plain text,
with no TypeSafe or OpenAI logos, and no other studio's characters, names, sprites, stages or
sounds are used.

## Video

One committed video. It is generated from the repo's own match logs and drawn entirely with the
original art above. No footage, image or sound from anywhere else is in it.

| File | What it is | How it is made | Author | License |
|---|---|---|---|---|
| `public/media/arena-square.mp4` | The square cut of the published results: 1080 × 1080, 54.7 s, 60 fps, H.264, no audio, 12.1 MB. An intro card, then for each game a title card and the end of its featured match, then an outro card with each model's results | `pnpm cut --square`: the game renderers replay each featured match from its committed log in `results/<game>/matches/`, and the cards read `results/leaderboard.json`. Rendered in headless Chromium, encoded with ffmpeg | Malleable AI LLC | MIT |

The text in it is drawn in the system font stack above, so its glyphs come from the fonts of the
machine that rendered it. No font file is shipped. Vite copies `public/` into the build, so the
built app serves the file at `/media/arena-square.mp4`. Other renders go to `renders/`, which is
gitignored.

## Sounds

None. The games and the video have no audio, music or voice-over.

The build tools also use a fixed list of about 380 common first names to mask names in the SMS
sample. It is original work (MIT), in `src/cli/build-inbox-data.ts`. Names the AI reviewers
(Claude) found while reading the sample went into a local list that is never committed; its file
name, size and hash are recorded in `data/inbox/messages.json`.
