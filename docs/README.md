# docs

- `architecture/`: how the code is built. Kept current with the code; where they disagree, the
  code wins and the page gets fixed.
  - [architecture/core.md](architecture/core.md): the classifier core, option order, the
    schedulers, the validity rule and the run-level miss check, the exclusion list, log schema v2
    and run ids, results, replay, the cost estimate, scores, the tournament, the live proxy, the
    web shell, render mode, the video cards, and `pnpm render` and `pnpm cut`.
  - [architecture/games.md](architecture/games.md): the game contract, and how to add a game.
  - [architecture/fighter.md](architecture/fighter.md): the fighter's rules, moves, view, prompt,
    baselines, cost estimate, renderer and tuning.
  - [architecture/inbox.md](architecture/inbox.md): Inbox Invaders' rules, view, prompt, data,
    baselines, cost estimate, tuning and renderer.
  - [architecture/clues.md](architecture/clues.md): Clue Clash's rules, view, prompt, boards,
    originality checks, cost estimate and renderer.
  - [architecture/providers.md](architecture/providers.md): the provider registry, the fairness
    rules every provider inherits, and how to add a provider.
- `research/`: dated facts about the APIs and datasets this repo uses, with sources.
  - [research/decision-apis.md](research/decision-apis.md): Jev and OpenAI Decisions, other
    decision models, the API spike's findings (shapes, latency, tokens, order sensitivity) and the
    cost model.
  - [research/game-data.md](research/game-data.md): the game datasets, their licenses, the Inbox
    label check and the Clue Clash board review.
- [assets.md](assets.md): where every font, piece of art and dataset comes from, what the
  committed video is and how it is made, and each one's license.
- `briefs/`: the intended behavior of a change, written before it's built (`skills/brief-creator`).
  Temporary; empty when nothing is in flight.
- `plans/`: code-level plans made from a brief (`skills/brief-to-plan`). Temporary; empty when
  nothing is in flight.

Once a brief is built, delete it and its plan, and move anything lasting into `architecture/` or
`research/`.

Outside `docs/`: [../results/leaderboard.md](../results/leaderboard.md) and each
`results/<game>/summary.md` hold the published results (generated by `pnpm leaderboard`; don't
edit them), and [../data/NOTICE.md](../data/NOTICE.md) holds the dataset credits and licenses.
